## What it configures

The config-level manifest AND the canonical definition of the rule envelope every config item carries. This is the ONE home for the shared envelope: each section file's meta describes only its own nodes and its own kind-specific `spec`, and refers here for `governs` / `kind` / `status` / `validation`. Do not restate these vocabularies in a section file — a second copy is how the same concept ends up defined four ways (the failure reconciliations.json exists to record).
