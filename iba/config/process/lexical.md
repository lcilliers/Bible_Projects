A length floor and a truncation check catch the 07-14 artefacts (malformed, truncated-mid-word values) but would pass a well-formed, uninterpretable value.
  - _recommendation:_ B — the [C] floor runs over everything and catches the known artefact class; the [I] judge samples and cannot self-certify because it judges a DIFFERENT model call's output. C is disallowed by the design's own logic.
  - _resolve by:_ researcher decision
- **`open.lexical.sense-authority-check`** — `gate.lexical.sense-matches-subgloss` is the gate for the dimension that failed hardest (D101 recorded interpretation, not the sub-gloss). But matching a produced sense against a lexicon sub-gloss is fuzzy, not exact — the sub-gloss is a gloss list, and the read must pick the per-occurrence one.
  - _recommendation:_ A first, and see what it rejects. The 07-14 failure was not a near-miss — 'public good' for tsaddiq is not a sub-gloss at all, and a strict gate would have caught it on the first row. Loosen only against evidence.
  - _resolve by:_ researcher decision
- **`open.lexical.compound-shapes`** — D109 shape `pair/flag` and D117 shape `value/pair` are not members of enum.pair_kind, so `gate.lexical.shape-matches-pair-kind` cannot run for them. Both FAILED on 07-14.
  - _recommendation:_ Model the head and the pair as two rows (head value + optional pair row), so every stored row has one simple pair_kind and the gate is total. Carried from dimensions.json meta.open.compound-shapes.
  - _resolve by:_ researcher decision
- **`open.lexical.regex-prohibition`** — Five dimensions (109/111/117/118 + 110) were RETROFITTED BY REGEX and all failed. `lexical.no-mechanical-extraction` states the prohibition, but a [C] gate cannot see HOW a value was produced — only what it looks like.
  - _recommendation:_ A + C. C makes it structurally impossible; A makes it detectable if someone routes around C. B alone is what we had.
  - _resolve by:_ researcher decision
