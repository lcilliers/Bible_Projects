## 2. The working model — what a bite is, in / out / roll-up (labelled: hypothesis)

Stated as the shape the register points toward, for stress-testing tomorrow.

**The governing distinction.** The **M-clusters are characteristic-nodes** (fear, love, wisdom); **T3 is the operation-verbs** (say, give, come, take, and the body-acts); **the verse is the edge** between them. A characteristic rarely acts alone — it acts *through* an operation, *upon* a target. So **T3 comes into focus as the operation-edge of an inner-being movement**, not as a separate subject to be read on its own. (Whether T3 *also* earns bites of its own is **D3**, below.)

**IN to a bite** (bite provisionally = one lemma's verse-set within one cluster):
- the M-lemma + morphology;
- its inner-being verse-set;
- per verse: the text, the citation, and the **co-present lemmas** — the other M-characteristics and the T3 operations sitting in the same verse. (Without the co-present lemmas a bite can only ever see one node, never a thread.)

**INSIDE the bite** (W1 + the M1 Operation scaffold, per verse):
- decompose the movement — name / source / target / what-it-does;
- record the functional edges — cause, operation/how, object + object-kind, manner, effect, immediate-response, transition, binding, direction;
- each edge stated as **resolved / NONE-silent / UNRESOLVED**, with citation;
- run the discovery-lookout;
- **T3 surfaces here**, as the value on the operation edge (and often the object edge).

**OUT of a bite** — three products; the third is what the web is built from:
1. the per-verse movement records;
2. an in-verse (level-1) finding for the lemma;
3. the **out-edges** — every edge whose far end lies *outside this verse* (another characteristic, a T3 operation, a target belonging to another cluster, an unstated source). **These out-edges are the threads.**

**In-verse edge vs thread.** If both ends sit inside the verse, the edge builds the *local* movement and stays in the bite. If one end points elsewhere, it is a **thread** that rolls up. That single distinction separates "what stays in the bite" from "what comes out for the web."

**ROLL-UP** (W2, four-level cascade):
- L1 in-verse (done in the bite) → L2 similar-verses (group records of the same shape) → L3 cluster (synthesise the lemma findings into the cluster's movement picture) → L4 cross-cluster (match threads that ran *between* clusters).

**What the roll-up DOES:** turns isolated per-verse records into **movement patterns** (a characteristic's typical source / operation / target / effect), and **assembles the web** at L3–L4 by matching threads end-to-end. Unit of a pattern = the movement, not the term (C3).

**What the roll-up NEEDS** (and does not yet have):
- a **shared connector vocabulary — the join key** (D4): threads only match if a "target: a person" out-edge from the *love* bite and the equivalent from the *fear* bite are recorded in the *same* vocabulary; otherwise the result is 3769 isolated nodes and no web;
- the **silence discipline (C5)** carried into every bite, so a missing thread is recorded absent, not invented.

**The spiderweb is not a separate step.** It is what the out-edges *become* when the join key lets them meet at L3/L4. Each bite hands up nodes (characteristic-movements) and threads (out-edges); the cascade matches threads; the web grows bite by bite and is whole only when the last cross-cluster thread is matched.

## 3. Reflection on scale (~400–500 cycles) (labelled)

- At that volume the **join key (D4) stops being a detail and becomes the whole game.** 400–500 bites each emitting threads recorded in an ad-hoc vocabulary will not assemble; the same 400–500 emitting threads in a shared vocabulary will.
- The standing failure mode (sample / automate / complete-over-correct under volume pressure) is **most dangerous exactly here.** Many small bites means many boundaries, and boundaries are where cross-verse texture is silently dropped (W1 is blind to it by design; only the roll-up recovers it). An explicit, non-skippable roll-up obligation is the guard.
- Cultural / translation note: the cluster names are English-gloss conveniences (W10 — *workspaces, not meaning classes*). A cluster-first bite order risks treating the gloss labels as the inner being's own joints. Any reader from a different anthropology (tripartite vs bipartite; heart- vs mind-centred) should be told the clusters are arrangement, not claim — and the same caution applies to the stem-grouping in the overview report.

## 4. Decisions that must be settled before commencement

None of these is decided here. Each is the researcher's to steer. IDs are stable so we can refer to them tomorrow.

- **D1 — What is a bite (the base unit)?** cluster / lemma-within-cluster / stem-grouped-meaning / verse-set. *Drives the ~400–500 count and everything downstream.* (working model assumes lemma-within-cluster)
- **D2 — Micro-window application.** One **lead** per-verse window (W1) with W5/W6 as lookouts, or **all** run on every verse?
- **D3 — T3 role (load-bearing).** Operation-**edge only** (T3 never read for its own sake), OR **also its own bites** whose operation-movements characteristics attach to? This is the standing assembly choice: **recognise-then-attach** (previously your lean) vs **fragment-stitch** (only legitimate with a declared non-lemma join key).
- **D4 — The join key (load-bearing).** What do threads match *on* at L3/L4 — target-identity, operation-lemma, characteristic-pair, verse-locus, or a combination? *The web assembly rests entirely on this.*
- **D5 — Uneven cluster sizes.** Bite by cluster (variable-size bites) or normalise to a fixed verse/lemma count per bite (so M10 becomes many bites, M10b a single tiny one)?
- **D6 — Scope of the non-M clusters.** T2 (grammatical particles — *you, and, to be*) reads as **out**; FLAG is a review bucket — **in, out, or triage-first**? Confirm **T3 is in-scope as the operations layer** (its treatment is D3, not exclusion).
- **D7 — Aggregative attach point.** Do W2/W8/W9 run as a **roll-up** after a cluster's per-verse bites finish, or **continuously** alongside?

Take **one real M-lemma** (a mid-sized one from M05 Love or M01 Fear), run three or four of its verses through the §2 pipeline, and watch:
