### What exhaustive treatment caught that the selective first pass missed, on this ONE verse alone

1. **p0 (`G1063`, "for") was wrongly folded into "inert" in the first pass — it is a genuine causal
   connective**, the same category as Hos 2:4's `H3588A` and Exod 15:1's `H3588A`. A real
   misclassification, not a stylistic gap.
2. **Two connective shapes the checklist's current two-item set (chain / causal) doesn't name**:
   coordinating conjunction (`G1161`, ×2) and purpose clause (`G2443`). Both silently absent from
   the first pass rather than flagged as not-fitting.
3. **A third "desire"-family code** (`G2309`/"want," related to `G2307`/`G2308`) sitting in the
   same two verses as `G1937`/`G1939` — invisible without pulling related words for every content
   code; the first pass's selective pull would never have surfaced a three-way cluster.
4. **The flesh/Spirit case-morph mirroring (chiasm) is now traceable cell-by-cell** in the
   data-quality column, not asserted as a separate prose observation — the exhaustive format makes
   it a fact the table itself demonstrates, not a claim layered on top.

Nothing here contradicts the first pass's real findings (the *ou mē* and *ho ean* idioms both hold
up); the point is what exhaustive treatment adds — a real classification error caught, two new
connective shapes named, and a cluster the selective pass structurally could not have found.
