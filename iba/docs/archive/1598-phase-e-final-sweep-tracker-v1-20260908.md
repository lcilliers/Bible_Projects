  T2's own membership). This is genuinely the largest single thread in escalation #1598 — tracked
  here so nothing is silently skipped across what will be many turns/batches, not one sweep.

processed via Phases B1–B3 and the ~90 T2-noun-pool items already checked) have **no cluster row of
any kind** — not even `T2`. This is a distinct body of work from re-checking existing memberships:
it needs the same scan-and-classify treatment already applied to the verb pool, extended to the
much larger noun/adjective remainder. Not started as its own tracked thread yet — folding into the
same batch cadence as the M/T-code sweep above, cluster by cluster, is the current plan.
