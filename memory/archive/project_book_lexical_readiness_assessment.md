**Passage rule refined 2026-07-13 (researcher) — CHAR-CONTINUITY, not maximal-run, not thematic.** A maximal run of consecutive candidate verses is genre-blind: it BUNDLES sentence-collections (Prov 10–29 — each verse an independent proverb → whole-chapter "passages"; Pro 14:1–35 = 35 proverbs, tested 48/54 large passages spanned >2 discourse units). Correction: a passage continues only while consecutive candidate verses **share ≥1 candidate characteristic** (same base-Strong's); breaks on char-focus change. **Around the chars — NOT thematic `segment_unit` grouping** (theme distracts/overloads; the char is the heart). Tool: `_apply_passage_build_v2_20260713.py --book N --rule char-continuity` (default; `--rule maximal` for discourse/poetry-only). Proverbs: **104 bundles → 701 char-focused passages** (626 single-verse; mean 1.1 verses/3.0 chars; max 10 = fool cluster Prov 26:3–12).
