When referring to an IB-verse dimension, always pair the **code with its name** — "D2 Source", "D7 Process", "D9 Coupling", "D13 Cohabitation" — never a bare "D2"/"D9".

**Why:** the user does not hold the meaning of every dimension code in their head; a bare code forces a lookup and breaks the reading. They need to connect immediately with *what the dimension is*.

**How to apply:** in chat, observation tables, worklists, and any summary, render dimensions as `D<n> <Name>`. The canonical names are in `Workflow/Catalogue/wa-IB-verse-dimensions-catalogue-[current].md` (D1 Identity · D2 Source · D3 Seat/bearer · D4 Operation · D5 Object · D6 Manner · D7 Process · D8 Impact · D9 Coupling · D10 Valence · D11 Discovery · D12 Hidden · D13 Cohabitation). See [[project_dimension_d13_cohabitation]].
