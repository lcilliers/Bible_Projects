**Researcher, 2026-07-03** (during fork-b characteristic mapping): *"we are doing this at the risk of manufacturing stuff that does not exist — this should be noted. We should not force the verses into the list; we should use the list to validate that we are not missing something in verses, without imputing values."*

**The guardrail.** The characteristic baseline / `ib_characteristic` registry / any characteristic list is a **downstream index**, not a source. It exists to **validate coverage** — to ask *"does this verse raise an inner-being characteristic we failed to capture?"* — and nothing more.
- **Direction is one-way: verse -> list.** Read the verse first (verse-bounded, no import — [[feedback_lexical_strictly_verse_bounded_no_implied_evidence]], [[feedback_verse_meaning_grounded_not_imported]]); derive the operation FROM the verse; then use the list to check for OMISSIONS. **Never list -> verse** (hunting a verse for a pre-named list-item, or attaching a verse to illustrate a list-item = imputation).
- **The list never adds value to a verse.** A characteristic counts as "present" only where a *verse-grounded reading* actually captured it. If the list has an item the verse does not show, that is a MISS to leave empty, not a value to impute.
- **Manufacturing risk is real and must be NOTED.** Authoring characteristics + definitions + cited verses (as the 2026-07-03 baseline extension did) can silently impute — the definition generalises past what any verse says, and a list tempts forcing. When it happens, flag it and pare back to what the verse alone shows.
- **Emergence, not a grid** ([[project_RESET_characteristics_to_movements_changeover]], [[feedback_no_forced_structure_audit_surfaces_analysis_compensates]]): characteristics EMERGE bottom-up from verse-readings; the list is their tally, held open, growing/consolidating — it does not pre-decide content.

**Applies to:** the coverage-mapping step (count only reading-attested surfacings; use the list to spot MISSES to re-examine against the verse, without imputing); the baseline extension (its 78 entries are provisional validation-exemplars, to be verified verse-by-verse, not asserted); all future books.
