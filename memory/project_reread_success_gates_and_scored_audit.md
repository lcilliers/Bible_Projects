A book re-read's success is **measured, not asserted** (researcher direction, 2026-07-08). Method:
- **Nine hard gates G0–G8** — each a study objective turned into a SQL query with a pass value: G0 digestion budget (≤~12 char-spans/reading-unit), G1 nothing passed over, G2 worked-not-named (every characteristic has its operation read), G3 read-from-the-verse (every value carries a resolution state; no over-calls), G4 distinctions preserved (recurring terms not flattened), G5 belonging (cohesive multi-verse units show cross-verse links), G6 discovery-lookout ran on every verse, G7 honest uncertainty (no silent blanks), G8 better-than-before (positive delta, no unexplained drops). Spec: `verse-analysis/_reports/wa-proverbs-reread-success-criteria-20260708.md`.
- **Scored read-back audit** for what queries can't prove (correctness): sample ~25 units stratified, score sound/weak/wrong on fidelity · working-completeness · movement · distinction; **≥90% sound, zero fidelity failures**.
- **Baseline-then-delta**: run the gates on the CURRENT (pre-reread) state first and file it as the baseline (Proverbs baseline 2026-07-08 = 2/9 pass; `wa-proverbs-reread-BASELINE-20260708.md`), re-run the same script after the read to show improvement. Script `scripts/_check_proverbs_reread_measures_v1_20260708.py` measures active-current-state (provenance-agnostic) so one script gives before AND after.
