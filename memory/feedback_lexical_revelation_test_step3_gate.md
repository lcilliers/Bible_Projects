Researcher requirement 2026-06-24: deep evidence gathering must include tests for whether the **lexical is fully revealing**. Run the **Lexical-Revelation Test (LRT)** per unit at the START of step 3, before any object-type/characteristic conclusion.

**The 7 checks:** (1) were ALL fields considered (coverage of sense/object/object_type/experiencer/valence/how)? (2) EXPECTEDNESS — given the term's NATURE, which fields should be populated; an expected field that is empty = RED FLAG (lexical not fully revealing). (3) LOCATE the missing — verse_text? bound/co-seated term (often another cluster)? genuinely absent? wrong field? (4) CONTRADICTION (e.g. action-type with no object AND no how). (5) ODD ONE OUT (outlier occ = mis-owned/mis-glossed/sub-sense). (6) do the PARTS PLAY TOGETHER (coherent or fragmented). (7) VERDICT: fully revealing? if not, what's missing + recovery route.

**Expectedness rules (nature → demanded fields):** act/expression → sense·object·**how(manner)**·experiencer; state/condition → sense·**valence**; characteristic → sense·object·experiencer. Nature comes from lemma grammar (type) as a DESCRIPTIVE property only (sets expectations; does NOT assign object-type — that still flows from per-verse-varying fields, [[project_superstructure_eisegesis_validation_20260624]]).

**The principle (researcher's anchor):** giving's `how` CANNOT be null — an act has a manner; a null where the nature demands it means the lexical missed something real → find where it is, how to assess it. Demonstrated on M12: cleanness (state) valence 96% = fully revealing; holiness/consecr (act) how 4% = RED FLAG (manner missing, object/valence rich); giving (act) how 0% = RED FLAG whose recovery EXPOSED a split — a small willing/heart-bound giving (an EXPRESSION, manner recoverable from verse-text + M09/M05 bindings, [[feedback_expression_vs_characteristic_object_type]]) inside a large mass of bare transactional transfer (no manner, not inner-being). The lexical lumped both as "give".

**How to apply:** run `scripts/_lexical_revelation_test_20260624.py --strongs … --nature …` per unit; each deep-evidence file carries an LRT section + verdict; flagged gaps feed a programme **lexical-remediation backlog** (esp. how/manner on act-lemmas — the validation's predicate-on-partner-verb defect).
