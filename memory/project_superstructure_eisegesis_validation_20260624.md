Researcher mandate 2026-06-24: stamp out the recurring AI reflex of getting a concept then making the evidence fit it (eisegesis), vs gathering evidence and reflecting what it says (induction). Validated ALL M10+M11 work via **cold read against the lexical** (the trusted, low-error base — NOT the root verse; root-verse recourse = a logged lexical defect). Five independent validators + a pilot, all converged.

**Verdict:** ~70-85% of analytical CLAIMS import meaning the lexical does not carry (M11 67%, M10 char/cond 83%, record/identity 62-75%, expr/mech/remedy/agency 86%, structure 80%). BUT the imposition is **entirely in the superstructure** — the §10 object-kind grid, the 32-unit structure, cross-cluster pole-pairs, the resolution sequence, all faculty-seatedness claims. **The base lexical sense-readings are SOUND** (researcher was right the lexical is low-error).

**MECHANICAL CAUSE (provable):** `faculty`/`type`/`lemma_meaning` are LEMMA-CONSTANTS — they never vary across a term's occurrences (faculty 0/86 M10 terms, 0/15 M11; type 0% M11). The §10 grid is keyed to type/faculty ("type=action→characteristic", "faculty=X→X-seated"), so it RELABELS a fixed lemma tag as a per-verse discovery. Legit per-verse evidence = **sense/object/object_type/experiencer (+ partly valence) + co-seatedness**. GOVERNING RULE: an object-kind/characteristic call must cite a per-verse-VARYING field; NEVER type/faculty.

**What SURVIVES (earned per-verse):** defilement #29-32 = non-moral CONDITION (valence varies within-lemma); M11 #2 forgiveness act+state, #3 release multi-register, #4 human/divine experiencer split; sin↔righteousness pole-pair (81 shared verses); #17 guilt = a conscience-OPERATION (so MIS-FILED as "record", it's a characteristic).

**What FELL:** RECORD/LEDGER object-kind = absent from the lexical entirely (0 occ of record/ledger/tally in 1904 verses; accounting predicate always on a partner verb); char-vs-condition = a type-tag relabel; 32-unit structure largely interpretive (of ḥāṭāʾ #1-7 only #2 Unintentional is lexically visible; `how` field 0.4% coverage); written↔blot & corruption↔incorruptibility pole-pairs IMPOSED.

**Specific factual corrections logged:** M11 resolution sequence rests on the WRONG shuv (H7725N = recall-to-mind, NOT moral turn-from-sin which is M45's); na.cham obj=disaster 23/34 (God relents about punishment, not from sin — "bilateral repentance" CONTRADICTED); #5 reconciliation katallassō=action (the "state/9th-kind" lives only in co-term katallagē filed under M05); a.von "tri-fold" = a sub-entry split (H5771G/H/I), not one lemma read 3 ways, and the punishment sub-entry is external-pole (out of scope); cha.val mis-gloss; 2Co 11:3 missing from corpus.

**LEXICAL DEFECT (researcher asked to know):** the lexical is accurate but INCOMPLETE on relational/operational predication — when a verse's key predicate lives on a PARTNER verb (engraved=cha.rash, count=logizomai), it is never folded into the sin-term's how/object (left empty); how-coverage ~56% M10 / 3% M11. So per-verse operational claims have little lexical support — exactly where the analysis reached for verse-text and over-read.

**Remediation DEFERRED** (surface extent first). Path: demote/re-derive the §10 grid from per-verse fields only; treat units as provisional; drop faculty-seatedness claims programme-wide; fix §5 errors; optional lexical-completeness pass (fold partner-verb predicates).
