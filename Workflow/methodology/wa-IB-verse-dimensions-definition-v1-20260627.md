# IB-verse-dimensions — definition (the schema for capturing an inner-being operation)

- **File:** wa-IB-verse-dimensions-definition-v1-20260627.md · **2026-06-27 · Author:** Claude Code.
- **Objective (a):** capture the IB **operation** from a verse — starting here, with the **dimension definition**. Derived from the Exo 1:13 raw collection; the dimensions are a *starting, revisable* set (the `D11 Discovery` slot keeps it open).
- **Discipline:** stay focused (the raw material is rich; easy to digress). Each dimension is defined by *what it captures · how it is evidenced · its value · its states*.

## 1. The unit = an IB OPERATION
- The record is an **IB operation** (an inner-being movement in the verse), **one per fan-out track**. A verse may hold several (Exo 1:13 has two: ruthlessness, enslavement).
- Each operation is described across the **dimensions** below. Each dimension value carries: **value** (or NONE/silent) · **status** (`resolved` / `needs-corroboration` / `silent`) · **provenance** (mechanical / researcher / logos / claude-chat / scholarship) · **basis** (the citation/morphology/contributor it rests on).

## 2. The dimensions (definition)
| # | dimension | the question — what it captures | how it is evidenced |
|---|---|---|---|
| **D1** | **Identity** | *what is the operation?* — the named inner-being movement | the span + lemma/sense + morphology |
| **D2** | **Source / antecedent** | *where does it come from?* — driver / cause / motive (incl. from context) | causal clause; the operation in a prior/context verse; the actor's prior state |
| **D3** | **Seat / bearer** | *where is it seated / who bears it?* — named seat (heart/soul/spirit) or the bearer | a seat lemma in-verse; else the grammatical subject (bearer) |
| **D4** | **Operation / action** | *what does it do?* — the act itself + its grammatical realisation | the predicate + **stem** (Qal=simple · Hiphil=causative · Piel=factitive) |
| **D5** | **Object / target** | *on whom / what?* — the patient/recipient | accusative / object marker / prepositional complement |
| **D6** | **Manner** | *how is it done?* — the qualifier on the operation | manner phrase / adverb / intensifier |
| **D7** | **Process / movement** | *how does it unfold / morph?* — the dynamic chain | the sequence of operations/states; causative stems; result/sequence clauses |
| **D8** | **Impact / produced state** | *what does it produce?* — the effect/outcome state in the object | result clause; the produced-state verb (e.g. *marar* Piel = made bitter) |
| **D9** | **Coupling / relation** | *what binds with it?* — relations to other operations/terms | grammatical binding; co-occurrence (in-verse + corpus) |
| **D10** | **Colour / valence** | *moral register — WHERE EVIDENCED IN THE VERSE* (never imported) | term-inherent moral lemma; prohibition; the verse's framing |
| **D11** | **Discovery** | *anything the dimensions do not capture* (emergence) | the lookout — feeds new dimensions back |

**Completeness of an operation** = every dimension swept (a value, or marked *silent*) + D11 checked. **Complete ≠ resolved** — most values may be `needs-corroboration`.

## 4. Objective (b) — tracing the fan-out (the hard one) — approach, not yet built
The fan-out reaches the related verses (perek 6 · abad-Hiphil 8 · the conceptual sets from Logos/Claude). Each must be *completed* too — and the danger is combinatorial explosion. The discipline that tames it:
- **The fan-out is driven by the OPEN dimensions, not by every shared term.** You fan out to **corroborate the `needs-corroboration` values** (e.g. *does dread→cruelty hold?* · *is cause-to-serve valence-neutral?*). A related verse is worth completing insofar as it can resolve an open dimension.
- **Convergence terminates it.** Once independent verses + contributors converge on a dimension's value, it flips to `resolved` and **stops driving new fan-out**. The worklist contracts as the debate refines.
- **Dimension-keyed accumulation:** observations on the same operation × dimension accumulate across verses; a recurring, converged answer **is a focus point**.
- So: a worklist of related verses, prioritised by *which open dimension they can close*, processed until the open dimensions converge — not an exhaustive sweep of every shared term.
