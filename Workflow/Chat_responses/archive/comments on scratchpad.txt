	Word: a word is set by the researcher; it is used the return the related strongs from STEP
	strong: not all strongs returned in the STEP search is relevant. The strongs selected must be relevant to the study. This is a key gate to be defined
	verses: The verses selected is determined by STEP strong related verses. In many cases verses is returned by STEP (often thousands) of which only some is relevant to the study. This is a second key gate to be defined.
	span: every verse have span for a number of words determined by STEP.  Not every span is used in the study. Relevancy cannot be determined at the point of creation. Therefore the full span is generated for every verse included in the study
	meaning: the meaning tables (raw and parsed) must include details for every strong. But this is much more complicated than the surface sounds.  It is not sure how, and where the gate for meaning proliferation should be controlled.
	lexical: the lexical is the application of meaning of the strongs in a verse.  The gate for a lexical is defined as the best application of the meaning of the strongs within the context of the verse for the strongs that is included in the study - but not all the strongs apply because some strongs are generic/language particles/marginally relevant/ not relavant / unsure - so this creates a gate that is constantly moving around.
