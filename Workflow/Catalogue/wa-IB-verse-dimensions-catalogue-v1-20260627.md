# IB-verse-dimensions — CATALOGUE (codes + wording)

- **File:** wa-IB-verse-dimensions-catalogue-v1-20260627.md · **2026-06-27** · the controlled reference for the inner-being verse dimensions. Definition: `Workflow/methodology/wa-IB-verse-dimensions-definition-v1-20260627.md`.
- **Use:** the codes (`D1`–`D11`) are the controlled vocabulary that every observation is coded to. Revisable — `D11 Discovery` feeds new dimensions back.
- **Unit:** an IB **operation** (one per fan-out track); each operation is swept across all dimensions. An **observation** = one thought, a narrative coded to a dimension, **term-anchored**.

| code | name | wording (the question asked of the verse) | what it captures |
|---|---|---|---|
| **D1** | Identity | *What is the operation?* | the named inner-being movement (the act/state itself) |
| **D2** | Source / antecedent | *Where does it come from?* | the driver / cause / motive (incl. from context) |
| **D3** | Seat / bearer | *Where is it seated, and who bears it?* | a named inner seat (heart/soul/spirit…), or the bearer (the actor) |
| **D4** | Operation / action | *What does it do?* | the act + its grammatical realisation (the stem: Qal simple · Hiphil causative · Piel factitive) |
| **D5** | Object / target | *On whom or what does it act?* | the patient / recipient |
| **D6** | Manner | *How is it done?* | the qualifier on the operation (adverb / manner phrase / intensifier) |
| **D7** | Process / movement | *How does it unfold or morph?* | the dynamic chain — what it becomes, what follows |
| **D8** | Impact / produced state | *What does it produce?* | the effect / outcome state in the object |
| **D9** | Coupling / relation | *What binds with it?* | relations to other operations / terms (in-verse + corpus) |
| **D10** | Colour / valence | *What moral register — where the verse evidences it?* | moral colour, only where stated/mechanical; never imported |
| **D11** | Discovery | *What do the current dimensions not capture?* | the emergence slot — feeds new dimensions back |

**Completeness of an operation** = every dimension swept (a value, or `silent`) + D11 checked. **Complete ≠ resolved.**

## The observation record (the unit captured against these codes)
One **thought** per observation — a narrative coded to a dimension. A dimension may carry many observations. Fields:
- **dimension** — `D1`–`D11` (the code)
- **narrative** — the thought (the wording)
- **term_anchor** — the Strong's it is anchored to · **MANDATORY** (an un-anchored observation is a *phantom*)
- **origin_verse** — the verse it arose from
- **reconsider_at** — where it should be revisited / corroborated (a verse or a term) — the forward thread that drives the fan-out
- **status** — `resolved` / `needs-corroboration` / `silent`
- **provenance** — `mechanical` / `researcher` / `logos` / `claude-chat` / `scholarship`
- **basis** — the citation / morphology / contributor it rests on
- **operation** — the IB operation / track it belongs to
