# Reading projection — preamble (how to read these files)

Ships with every book projection. Full spec: `Workflow/methodology/WA-projection-schema-and-companion-spec-v1-20260714.md`.
Generated by `scripts/_build_projection_v1_20260714.py --book <id|all>` (read-only) from the re-read layer.

## The four files (per book, in `<book>/`)
| file | grain | use |
|---|---|---|
| `<book>_reading_view.csv` | **one row per reading** | the analyst file — flattened, 51 columns |
| `<book>_nodes.csv` | one row per reading | technical: every raw span/ib_char/verse field |
| `<book>_edges.csv` | one row per span-id pair | **the movement graph** — coupling/bearer/target links (build the web from here) |
| `<book>_dimensions_long.csv` | one row per ve_lexical row | full fidelity — any pivot the reading_view loses |

## The two state codes — DO NOT collapse to blank
- **`NONE`** = the reader **looked and found none** (`ve_lexical value='none'`). **This is evidence of silence.**
- **`ABSENT`** = **no row was read** for that dimension. **This is NOT evidence of silence — it is absence of reading.**
Reading `seat=NONE` and `intensity=ABSENT` as the same thing is the single most important error to avoid.

## Base meaning vs verse-derived nuance — three layers, kept distinct
Flattening does **not** collapse the base word-meaning into its contextual nuance. Read them together:
1. **Lemma (base)** — `lemma`/`strongs` + **`base_gloss`** — INVARIANT across every occurrence (e.g. H3045 `base_gloss="to know"`).
2. **Meaning-in-context** — `ib_char`, `char_key`, `read_sense_variants` — the derived nuance the word takes (H3045 → know / teach / regard / **feel-insensible** / …).
3. **Occurrence** — `span_id`, `sense`, `operation`, `reading`, `verse_ref` — this verse's reading (the finest grain; two same-nuance readings are still distinct rows).
To analyse difference: group by `lemma`, compare `base_gloss` against each reading's `sense`/`reading` to see how far context pulls the word.

## Key columns
- **`reading`** (was "discovery", ve_nr 114) — the evidence-anchored note: transliteration + capitalised verse-quote + meaning + the surfaced finding. **The primary evidence text.**
- **`discovery_flag`** (derived) — `present` if `reading` carries a surfaced finding, else `absent`. Filter on it to find the gems. *(heuristic — derived from text.)*
- **`coupling`** — the pairing **phrase**; the **graph edge** for it is in `edges.csv`.
- **`role`** = characteristic / qualifier / standalone. **`locus`** = internal:ib-state / external:god / external:person.
- **`char_candidate_tag`** — `emergent-read-2026` / `orphan-reread-2026` = a characteristic the old model missed (a finding in itself).
- **Salience:** `lemma_freq_book` (major vs minor characteristic in the book), `ib_instance_count` (corpus-wide).

## Derived / heuristic columns — treat as review-grade, not authored
- **`translit`** — parsed from `reading`/`sense` (~87% Proverbs; lower Psalms — the older-style rows). `translit_conf` = head / embed / none.
- **`object_kind`** — god / person / self / abstraction / other / none, inferred from `target`+`bearer`+`locus`. `other` = uncategorised (not asserted).

## Qualifier-derived dimensions — `intensity` / `specifier` / `effect` / `direction`
These are **assessed from the qualifier spans / pairs around the characteristic**, and recorded as `NONE` (assessed, none) or a value — **not silently `ABSENT`**:
- **`intensity`**(109) — from the degree/modifying qualifier ("greatly", "very", a doubled verb).
- **`specifier`**(110) — from the narrowing qualifier ("of the LORD", "this").
- **`effect`**(111) — from the result/consequence qualifier (also recorded at Phase-2 book level).
- **`direction`** — the movement vector (toward-god / inward / outward / reciprocal) from the pair.

**Note (transition):** the *current* projection may still show these `ABSENT` on some rows until the **retrofit pass** (linking modifying qualifiers to their char and filling the dimension) completes on Psalms + Proverbs; thereafter `ABSENT` means only a genuinely unreadable case, and every other row is `NONE`-or-value. See `WA-projection-schema-and-companion-spec-v1` §C.2 / §E.

## Genuine gap (flagged, not silently blank)
- `hebrew_form` — empty: the stored `surface_en` is the **English** ESV word; the Hebrew surface is not stored (derivable via STEP).
