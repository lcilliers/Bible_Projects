## 3. What these tests do not show

- They do not test the quality of an evaluation or a finding: the code checks form, coverage and consistency, not whether a
  surface was judged rightly (specification 4.1, 4.2). That is the reading's work.
- A reading was not run end to end on live data; the researcher's test is the first.
- The claims steps (Synergy to Publish) were checked only for presence (X3), not run.
- Reading.ps1 itself (the PowerShell wrapper and the colour output) was not run, because it opens the live database; the
  dispatcher it calls was run on the copy (second test).
