> **comment (set this version):** Root cause found (researcher's own follow-up, this chat turn: pivoting by tag in practice, expecting it to differentiate after window's grouping already works -- it doesn't). Checked charanswergenerate.py's own prompt directly: the tag_values query pulls ALL 19 active cfg_enum values with no stage filtering, so every tag IS technically offered to the model -- but the prompt only gives explicit usage guidance for 3 of the 19 (needs_adjacent_verse_context, could-not-resolve, answered-no-flag), and answered-no-flag is explicitly framed as the catch-all: 'Use answered-no-flag for a plain, substantive answer with nothing else to categorise.' The other 16 registered values -- including cluster-pole-positive/cluster-pole-negative, which read as exactly the kind of differentiator that would break the 84% bucket into something useful -- are named in a bare list with zero explanation of what they mean or when to apply them in this stage's own context. Confirmed live: 11 of the 19 registered tag values have NEVER been used in ANY char-answers observation at all (cluster-pole-negative/positive, tightly-related, verse-grouping, difference-inference, surface-gloss-divergence, sole-mcode-in-verse, attested-pre-nt, nt-coinage, qualifier-for-term, data-error) -- though some of these may genuinely belong to Stage 3's own vocabulary rather than Stage 4's, not all 11 are necessarily a Stage-4 gap.
> **resolution (set this version):** Not a monitoring item anymore -- this is now a concrete, actionable prompt-design fix: add explicit per-tag usage guidance to charanswergenerate.py's _instructions for at least cluster-pole-positive/cluster-pole-negative (the most obviously-applicable-to-char-answers candidates), same shape as the existing 3-tag guidance block, so the model has an actual basis to choose them over the answered-no-flag default. Whether the other unused tags belong here at all, or are correctly Stage-3-only, is a smaller follow-on question. Not built this turn -- researcher's own call on priority against the other open escalations.
