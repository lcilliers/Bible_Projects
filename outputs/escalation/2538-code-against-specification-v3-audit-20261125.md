## Code defects this audit exposed (found only by running the verbs) and what was done
1. `LayerCheck -Subgroup` demanded the other subgroups' 1.1 rows, so no step could close for a subgroup (my change of the same day). FIXED (layerreading.check).
2. A word with no surface of its own (58 live verse_lexical rows, folded into another word's unit) was typed a partner and refused a whole 2.1 file. FIXED (collectionevidence.build_pairs: no partner without a surface).
3. A subgroup's answer `delete_neither` deleted observations that other collections hold (3,026 foreign nodes in the first run). FIXED (buildvalidate: refused for an observation held by another collection or subgroup, with the instruction to defer it).
Fixture mistakes of mine, corrected and not code faults: an independent partner set that counted `associated` links (the code's member tiers are right); one text for two subgroups (the code's duplicate refusal is right); a 3.1 node on a partner word (the code's refusal is right); keeps without node notes; sidecar files left by a killed run (a corrupt copy).
